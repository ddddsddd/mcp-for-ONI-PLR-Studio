# 02. Емкостной водонагреватель УАП-400/0,9

Перевод схемы управления водонагревателем УАП-400/0,9 (рис. 18.1, б) на программируемое реле ONI PLR.
Промежуточное реле **KV** исходной схемы заменено реле PLR: термоконтакт **SK** подан на вход `I1`,
выход `Q1` включает контактор **KM** (ТЭНы) и сигнальную лампу **HG**.

Файл проекта: [`vodonagrevatel.xlg`](vodonagrevatel.xlg) (ONI PLR Studio: *Файл → Открыть…*).

## Принципиальная схема

![Принципиальная схема с ONI PLR](principal.png)

Исходник схемы — [`principal.svg`](principal.svg).

| Обозначение | Назначение                                                        |
|-------------|-------------------------------------------------------------------|
| FU1–FU3     | предохранители силовой цепи                                       |
| KM          | контактор ТЭНов (силовые контакты и катушка)                      |
| EK1–EK6     | ТЭНы, 6 шт., по 2 на фазу, соединены звездой с нулём N            |
| SF          | автомат цепи управления (питание реле PLR)                         |
| SK          | термоконтакт (датчик-реле температуры), размыкается при нагреве   |
| R, HG       | добавочный резистор и сигнальная лампа «Нагрев»                    |
| ONI PLR     | заменяет промежуточное реле KV                                    |

## Входы и выходы реле

| Вывод реле | Подключение                                                          |
|------------|----------------------------------------------------------------------|
| `L`, `N`   | питание реле через SF                                                |
| `I1`       | термоконтакт SK: замкнут, пока вода холодная                          |
| `Q1`       | катушка KM и параллельно лампа HG с резистором R (как в исходной схеме) |

## Программа

![Схема программы (рисунок)](program.png)

Один вход напрямую соединён с выходом: `I001 → Q001`, т. е. `Q1 = I1`.

- вода остыла → SK замкнут → `I1 = 1` → `Q1` включает KM → ТЭНы греют, горит HG;
- вода нагрелась → SK разомкнулся → `I1 = 0` → `Q1` отключает KM → нагрев выключен, HG гаснет.

Это ровно логика исходной схемы: SK → катушка KV → контакт KV → KM и HG.

## Проверка в симуляторе

Откройте проект и нажмите **F3** (*Инструменты → Запустить симулятор*). Щелчок по `I001` включает
вход — `Q001` должен включиться; повторный щелчок — выключиться.

## Как сделан файл

Проект собран скриптом [`build_xlg.py`](build_xlg.py) из блоков проекта
[01_pusk_stop](../01_pusk_stop/) (тот же формат и модель **PLR-S-CPU-1410**): взяты блоки `I001`,
`Q001`, комментарий и одна линия связи. Если ONI PLR Studio покажет ошибку при открытии, соберите
схему вручную за минуту: блок входа `I1`, блок выхода `Q1`, соединить их линией.

> Питание реле и входов на схеме показано для версии ~220 В. Для модели с питанием =24 В подайте на
> `L/N` (`+/−`) и на термоконтакт SK напряжение 24 В от блока питания, а выход Q1 (релейный) так же
> коммутирует катушку KM ~220 В.
