# Программы для ONI PLR Studio

Проекты (`.xlg`) для программируемых реле ONI PLR, сделанные в среде
[ONI PLR Studio](https://oni-system.com/podderzhka/po/).

## Программы

| №  | Программа                                      | Что делает                                                       |
|----|------------------------------------------------|------------------------------------------------------------------|
| 01 | [Пуск-Стоп с самоподхватом](programs/01_pusk_stop/) | кнопка ПУСК (`I1`) включает `Q1`, кнопка СТОП (`I2`) выключает |
| 02 | [Водонагреватель УАП-400/0,9](programs/02_vodonagrevatel_uap400/) | термоконтакт SK (`I1`) и выключатель SA (`I2`) через блок И включают контактор ТЭНов (`Q1`) и лампу (`Q2`); принципиальная схема с реле A1 |

## Инструменты

- [`tools/xlg_dump.py`](tools/xlg_dump.py) — разбирает `.xlg`, печатает блоки и связи и проверяет, что
  линии и записанные в блоках источники сигналов согласованы:
  `python3 tools/xlg_dump.py programs/*/*.xlg`

## Как открыть проект

1. Установите ONI PLR Studio — она входит в пакет **ONI PLR-430_PLC-410_430 Tools Pack** на сайте ONI
   (*Поддержка → Программное обеспечение*).
2. Скачайте нужный файл `.xlg` (на странице файла в GitHub — кнопка *Download raw file*).
3. В ONI PLR Studio: *Файл → Открыть…* и выберите скачанный файл.

Каждый проект создан в ONI PLR Studio и проверен во встроенном симуляторе (F3). Подробности —
в README внутри папки программы.
